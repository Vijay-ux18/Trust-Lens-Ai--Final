# Model Provenance

## malware_model.joblib

Model type:
Random Forest

Input:
54 structural PE features

Training data:
Third-party PE structural-feature dataset cited in the research paper.

The original training dataset is NOT distributed with this repository.

## multiformat_model.joblib

Model type:
Random Forest

Input:
10-dimensional TrustLens common feature vector

Training data:
Author-generated synthetic evaluation data.

The synthetic data were created for architectural feasibility
evaluation and should not be interpreted as real-world malware
detection performance.
